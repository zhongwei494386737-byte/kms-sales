① 概率频率模型
P(n) = f(n) / N
统计100期实际出现频率，对应理论概率 P_theory = k/T（双色球红球k=6,T=33）
② Z-Score 标准化
Z(n) = (f(n) - μ) / σ
μ=期望次数(N*k/T)，σ=标准差。|Z|>1.96表示显著偏离
③ 数学期望 EV
EV(n) = Σ P(win)×Payout
综合频率×理论收益率加权，正向EV号码优先
④ 排列组合
C(T,k) = T!/(k!(T-k)!)
双色球红球 C(33,6)=1,107,568，每组理论概率1/1,107,568
⑤ 遗漏分析
P_miss(n) = (1-p)^m
连续m期未出的概率，m越大回补期望越高（赌徒谬误修正）
⑥ 马尔可夫链
P(X_t|X_{t-1}) 转移矩阵
近20期状态转移概率，捕捉短期趋势延续性
⑦ 信息熵
H = -Σ p(n)·log₂ p(n)
熵越高号码越随机，低熵号码有聚集趋势
⑧ 贝叶斯推断
P(θ|D) ∝ P(D|θ)·P(θ)
以均匀先验更新后验概率，动态修正各号码出现信念
⑨ 博弈论优化
max ΣU(s_i) s.t. diversity
避免连号/同尾/全奇偶等常见模式，降低多人同选分摊风险
